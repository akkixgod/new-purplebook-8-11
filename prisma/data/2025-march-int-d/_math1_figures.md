## Q3 — `math1-q03-scatterplot.svg` (page 53)

- **Axes:** x from 0 to 8 (ticks/labels every 1), y from 0 to 16 (gridlines every 1,
  labels every 2). Italic `x` / `y` axis letters, italic `O` at the origin.
- **Line of best fit:** **y = 0.6 + 1.5x**, drawn from x = 0 to x ≈ 8.4. The line
  leaves the plot near (8, 12.6). Positive slope, intercept just above the origin.
- **Data points** (10 filled dots, read off the source grid on page 53):
  (0.4, 1.1), (1.5, 3.0), (2.2, 5.0), (2.5, 3.1), (3.5, 7.1),
  (3.6, 5.1), (4.3, 7.1), (4.4, 9.1), (5.5, 12.0), (6.7, 8.1)
- **Choice D** was clipped on page 53. Reconstructed as **y = −0.6 − 1.5x** from the
  A–C sign pattern (same four-choice layout as 2025-march-int-c Math M1 Q2).
- **Answer note:** the drawn line rises and has a positive y-intercept, so the key is
  **A** (`y = 0.6 + 1.5x`); B/D have a negative slope, C a negative intercept.
