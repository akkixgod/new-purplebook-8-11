## Figure notes

- Q12's and Q13's stimuli in `_rw1.json` hold only the surrounding prose. The chart title,
  axis labels, legend, and the table title and cells live solely in the SVG, so neither item
  renders its data twice.
- Q12 bar values were measured, not eyeballed: `scripts/_measure-rw1-q12-march-int-c.py`
  calibrates the y axis from the detected gridlines (y = 248.5 px → 15, y = 471.5 px → −5,
  11.15 px per unit) and then reads each bar's top edge. Canada is the one country whose
  Pre-FTA bar (≈ 4.7) is taller than its Post-FTA bar (≈ 3.1) — the relationship the correct
  answer (D) depends on. Mexico is the only bar below zero (≈ −1.5), and choice C quotes
  Costa Rica's Post-FTA rate as "about 13.5 percent", which matches the measured bar.
- Q13's table is numerically identical to the same item in `2025-march-int-a` (Q11) and
  `2025-march-int-b` (Q13); the SVG matches those files with the slug swapped.
